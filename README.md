# Movie Recommendation System

## Overview
This project is a Python-based movie recommendation system built with the MovieLens dataset. It explores user ratings data, prepares a user-movie matrix, and implements recommendation approaches based on collaborative filtering and similarity methods.

## Project Goal
The goal of this project is to recommend relevant movies to users based on rating behavior and item similarity.

## Methods Used
- Data cleaning and exploration with Pandas
- User-movie matrix creation
- Collaborative filtering with Singular Value Decomposition (SVD)
- K-Nearest Neighbors (KNN) using cosine similarity
- Basic data visualization

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- scikit-learn
- Jupyter Notebook

## Dataset
This project uses the MovieLens dataset containing movie metadata and user-generated ratings.

## Main Steps
1. Load movie and rating data
2. Explore and clean the datasets
3. Merge and prepare data for analysis
4. Build a sparse user-movie matrix
5. Apply SVD for collaborative filtering
6. Generate movie recommendations
7. Train a KNN model for similarity-based recommendations
